# 🧠 Памятка по работе VLESS Checker (vless-checker-gh)

## 🕒 Расписание (МСК)
Скрипт запускается **6 раз в сутки** (каждые 3 часа, только днем):
*   **06:00, 09:00, 12:00, 15:00, 18:00, 21:00**.
*   **Ночью (с 21:00 до 06:00)** — спит, лимиты GitHub не тратит.

## 🛠 Что он умеет (Протоколы)
Теперь проверяет не только VLESS, но и всё остальное:
*   **VLESS** (Reality, WS, GRPC)
*   **VMess** (Base64 ссылки)
*   **Shadowsocks** (включая "Reality" версии)
*   **Hysteria2** (с поддержкой обфускации `salamander`)

## ⚡️ Как работает "Умная Очистка" (Rule of 2 Mistakes)
Чтобы не тупить над мертвыми ссылками по 100 раз:
1.  **Первая ошибка**: Прокси помечается как "подозрительный" (`fail_count: 1`).
2.  **Вторая ошибка**: Прокси признается **МЕРТВЫМ** (`fail_count: 2`).
3.  **Черный список**: Мертвые прокси хранятся в `history.json` еще **7 дней**, но скрипт их **игнорирует** и не тратит время на их загрузку/проверку.
4.  **Автоочистка**: Если прокси "мертв" и не ожил за неделю — он удаляется из базы совсем.

## 🛡 Защита от таймаутов (GitHub Actions)
*   **Лимит цикла**: Скрипт проверяет прокси ровно **8 минут**.
*   **Частичное сохранение**: Если за 8 минут он не успел проверить всё (например, прилетело 5000 новых ссылок), он **прерывает тесты, сохраняет то, что успел**, и пушит результат.
*   **Продолжение**: Следующий запуск (через 3 часа) начнет с того места, где остановился (пропустив уже проверенных).

## 📊 Где смотреть результаты?
*   `sub.txt` — все живые прокси (Base64 подписка).
*   `sub_ru.txt`, `sub_de.txt` и т.д. — только проверенные (2+ успеха) по странам.
*   `history.json` — вся база данных со статистикой успехов и ошибок.

## 🥇 Рейтинги (Иконки)
*   🥇 **Ultra** (5+ успехов подряд) — самые надежные.
*   ✅ **Verified** (2-4 успеха) — стабильные.
*   🆕 **New** (1 успех) — только что найденные.
